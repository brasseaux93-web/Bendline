# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers pledge to make participation in Bendline a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of trade or engineering experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming, calm, constructive, and inclusive language
- Giving and gracefully accepting strict technical and code-accuracy feedback
- Focusing on empirical code accuracy, safety, accessibility, and learner clarity

Examples of unacceptable behavior:

- Harassment, derogatory comments, personal or political attacks
- Publishing others' private information without explicit permission
- Submitting plagiarized code-book text or proprietary exam-vendor questions

## Enforcement

Maintainers may remove, edit, or reject commits, pull requests, issues, or comments that violate this Code of Conduct. Instances of abusive behavior may be reported privately to the repository maintainers via GitHub Issues or direct repository contact.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1.
